# Using Skills Proportionately

Read a Skill only when its trigger actually matches the task. User instructions and the Personal AI Operating Manual take precedence over a Skill's default workflow.

For software work, route with `mvp-workflow-router` before using planning, test, review, worktree, or agent Skills. Do not load every related process Skill by default.

Use the smallest workflow that addresses the real risk. Search and reuse before creating a new artifact. Stop at the selected Direct, MVP, or Deep gate; do not independently search for more work.
