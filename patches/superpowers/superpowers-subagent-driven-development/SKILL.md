# Selective Delegated Development

Do not dispatch agents for Direct or normal MVP work. First confirm that tasks are independent, file ownership will not overlap, and the coordination cost is lower than working inline.

Give each agent one bounded deliverable and a stop condition. Use a single targeted review only for a named Deep risk or user request. A finding earns one evidence-based fix attempt; after that, surface the unresolved choice to the user instead of entering a review/retry loop.

Never dispatch agents merely to satisfy a process rule, to re-run unchanged checks, or to search for extra improvements.
