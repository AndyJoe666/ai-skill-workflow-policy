# Selective Parallel Delegation

Default to one agent for a single task. Parallelize only after confirming independent scope, separate files or read-only investigation, and no shared state.

Each dispatch gets one question, one scope boundary, and one expected report. Do not use parallel agents for routine implementation, related failures, repeated verification, or speculative review. Integrate once, then run only the verification required by the selected Router mode.
